# Contributing to bg-text

`bg-text` is a Bulgarian text-quality skill and reference set.

Maintainer: `Shteryan Nikolaev` (`AcTePuKc`)

## What to contribute

- Bulgarian language rules with reliable support
- editorial improvements
- UX/localization guidance for Bulgarian
- cleanup of inherited non-Bulgarian leftovers
- examples that improve clarity and consistency
- repository docs and metadata consistency

## Contribution principles

- Keep normative claims distinguishable from editorial practice.
- Prefer primary Bulgarian language sources when the claim is about norm.
- Mark UX and localization guidance as heuristics, not as universal grammar law.
- Do not reintroduce inherited non-Bulgarian identity, author-centric copy, or Russian-first assumptions.

## Where to edit

- `skills/bg-text/SKILL.md`
- `skills/bg-text/references/`
- `skills/bg-text/agents/`
- root docs such as `README.md`, `README.bg.md`, and `SKILL.md`

## Style expectations

- Bulgarian rules and examples should normally be in Bulgarian.
- Technical metadata may remain in English when it serves tools or integrations better.
- Keep examples concrete and easy to audit.

## Before submitting

- Check that the change matches the `A/B/C/D/E` reliability model.
- Check that new wording does not overclaim normative authority.
- Check that examples are natural for Bulgarian.
- Check that no inherited non-Bulgarian branding or identity has been reintroduced.
